# ヘルツシュプルング=ラッセル図 恒星分類 Canvas

150恒星の絶対等級×表面温度を Canvas に H-R 図プロットする天文学教育ツール。

## 機能

- 実在の主要恒星 60 件 + 合成データ 60 件を H-R 図にプロット
- 主系列星/赤色巨星/白色矮星/超巨星の領域ハイライト（各種別の表示切替可）
- 恒星クリックで名称・表面温度・絶対等級・光度・半径・スペクトル型を表示
- 太陽位置マーカー（十字線付き）
- スペクトル型 O〜M 色凡例・恒星名ラベル表示オプション
- 主要恒星データテーブル（スクロール対応）

## 技術メモ

- 温度軸は対数スケール（log₁₀(T)）、等級軸は線形
- 光度換算: L = 10^((4.83 - mag)/2.5) [L☉]
- 波長→色マッピングで恒星色を表現
- 単体 HTML + Tailwind CDN
